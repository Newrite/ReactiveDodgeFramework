# Reactive Dodge Framework: документация (русский)

- [Annotations.md](Annotations.md) — для аниматора. Какие аннотации ставить в клипы доджа, атак и стаггера и какую
  настройку каждая заменяет.
- [Keywords.md](Keywords.md) — для дизайнера. Кейворды на акторах, вещах и маг-эффектах: стоимость, цепочки, окна
  неуязвимости и идеального доджа, ресурс, атакующие.
- [CastOn.md](CastOn.md) — правила заклинаний на додж и идеальный додж: условия, касты, стоимость, момент.
- [Settings.md](Settings.md) — все настройки: ключ в ini, подпись в меню F7 и описание. Файл собирается
  автоматически из тех же текстов, что показывает меню.

Настройки лежат в `SKSE/Plugins/ReactiveDodgeFramework.ini`. В игре с установленным FLICK их можно менять в меню
(F7 → группа «Reactive Dodge»): кнопка «Сохранить в ini» записывает их в файл. Правила CastOn лежат в
`SKSE/Plugins/ReactiveDodgeFramework/CastOn/`.
