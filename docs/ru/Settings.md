# Настройки Reactive Dodge Framework

Справочник всех настроек: как ключ называется в `SKSE/Plugins/ReactiveDodgeFramework.ini` и как он подписан в меню
FLICK (F7, группа «Reactive Dodge»). Подписи и описания те же, что показывает меню. Файл собирается
автоматически (`tools/gen_settings_reference.py`); правьте тексты в `tools/gen_menu_translations.py`.

## Страница «Кнопки и ввод»

| В ini | В меню F7 | Что делает |
|---|---|---|
| `[Input] iDodgeKeyboard` | Клавиша доджа (клавиатура) | Скан-код; -1 = нет. Действует, если «Кнопка доджа от» = Свои клавиши. |
| `[Input] iDodgeMouse` | Кнопка доджа (мышь) | Номер кнопки мыши; -1 = нет. Действует, если «Кнопка доджа от» = Свои клавиши. |
| `[Input] iDodgeGamepad` | Кнопка доджа (геймпад) | Маска кнопки XInput; -1 = нет. Действует, если «Кнопка доджа от» = Свои клавиши. |
| `[Input] fBufferWindow` | Окно буфера | Сколько нажатие ждёт открытия своего окна. |
| `[Input] fDebounce` | Защита от дребезга | Нажатия ближе этого считаются одним. |
| `[Input] bHoldPressesDuringDodge` | Держать нажатия во время доджа | Нажатие во время доджа ждёт своего окна (атака, силовая, блок, следующий додж), а не истекает через окно буфера. |
| `[Input] fPowerAttackHold` | Удержание силовой атаки | Удержание атаки столько времени в додже превращает отмену в силовую атаку. |
| `[Input] sDodgeKeyAction` | Кнопка доджа от | Брать кнопку, которую игра назначила на это действие, на каждом устройстве, вместо клавиш доджа ниже. Значения: `None` = Свои клавиши; `Sprint` = Спринт; `Sneak` = Красться; `Jump` = Прыжок; `Shout` = Крик; `Activate` = Активация; `ReadyWeapon` = Достать оружие; `TogglePOV` = Смена вида. |
| `[Input] sDodgeTrigger` | Додж по | Нажатие: когда кнопку нажали. Тап: когда её отпустили не позже времени тапа, так что удержание делает другое действие кнопки (спринт...). Значения: `Press` = Нажатию; `Tap` = Тапу. |
| `[Input] fTapMax` | Время тапа | Тап: самое долгое удержание, которое ещё считается тапом. |
| `[Input] bDoubleTapDodge` | Додж двойным нажатием | Два нажатия одной клавиши движения делают додж в ту сторону (клавиатура). |
| `[Input] fDoubleTapWindow` | Окно двойного нажатия | Второе нажатие должно прийти не позже этого после первого. |

## Страница «Тайминги и окна»

| В ini | В меню F7 | Что делает |
|---|---|---|
| `[Timing] fStartup` | Разгон | Фаза разгона в начале доджа. Клип может задать своё аннотацией RDF_Motion. |
| `[Timing] fActive` | Активная фаза | Фаза на пиковой скорости. Клип может задать своё аннотацией RDF_Motion. |
| `[Timing] fRecovery` | Восстановление | Торможение до скорости выхода. Разгон + активная + восстановление = длительность доджа. Клип может задать своё аннотацией RDF_Motion. |
| `[Timing] fExitBlend` | Переход в бег | За сколько додж, прерванный бегом, передаёт скорость. Клип может задать своё аннотацией RDF_ExitBlend. |
| `[Timing] fActionExitBlend` | Инерция при отмене в блок | Инерция, переносимая в блок, затухает до нуля за это время. Клип может задать своё аннотацией RDF_ExitBlend. |
| `[Timing] fAttackExitBlend` | Инерция при отмене в атаку | За сколько секунд гаснет инерция доджа после отмены в атаку. 0 = сразу движение самой атаки (фреймворки атак выбирают спринт- и атаки в движении по скорости). Клип может задать своё аннотацией RDF_ExitBlend. |
| `[Timing] fChainFrom` | Цепочка с | С какого момента можно сделать следующий додж цепочкой. Клип может задать своё аннотацией RDF_ChainOpen. |
| `[Timing] fAttackFrom` | Атака с | С какого момента додж можно отменить атакой. Клип может задать своё аннотацией RDF_AttackOpen. |
| `[Timing] fBlockFrom` | Блок с | С какого момента додж можно отменить блоком. Клип может задать своё аннотацией RDF_BlockOpen. |
| `[Timing] fExitFrom` | Выход с | С какого момента додж можно прервать бегом (и прыжком). Клип может задать своё аннотацией RDF_ExitOpen. |
| `[Timing] iChainDodges` | Додж-цепочка | Сколько доджей можно сделать цепочкой после первого. 0 = ни одного, -1 = без ограничений. |
| `[Timing] fChainPressFrom` | Нажатие для цепочки с | Нажатие доджа раньше этого момента доджа отбрасывается, а не ставит следующий додж в очередь (против спама). 0 = считается любое. |
| `[Timing] sChainDodgesKeyword` | Кейворд цепочки | Маг-эффекты с ним прибавляют сумму магнитуд (округлённую) к доджам в цепочке. Считаются только маг-эффекты с Recover; Detrimental со знаком минус; выключенные условиями и развеянные не считаются. |
| `[IFrames] fIFrameStart` | Начало i-frames | Начало окна неуязвимости (для клипов без аннотаций). Клип задаёт своё аннотацией RDF_IFrameStart; кейворд i-frames может сдвинуть. |
| `[IFrames] fIFrameEnd` | Конец i-frames | Конец окна неуязвимости (для клипов без аннотаций). Клип задаёт своё аннотацией RDF_IFrameEnd; кейворд i-frames может сдвинуть. |
| `[IFrames] sIFrameKeyword` | Кейворд i-frames | Маг-эффекты с ним меняют i-frames на сумму магнитуд в миллисекундах: больше удлиняет в конце, меньше укорачивает с начала (и окна из аннотаций клипа). Считаются только маг-эффекты с Recover; Detrimental со знаком минус; выключенные условиями и развеянные не считаются. |

## Страница «Движение»

| В ini | В меню F7 | Что делает |
|---|---|---|
| `[Motion] fDistance` | Дистанция | Сколько юнитов проходит неотменённый додж. Пиковая скорость подбирается под неё. Клип может задать своё аннотацией RDF_Motion. |
| `[Motion] fRunSpeed` | Скорость выхода (с вводом) | Скорость в конце доджа при зажатом направлении, лучше совпадает со скоростью бега. Клип может задать своё аннотацией RDF_RunSpeed. |
| `[Motion] fMaxCarrySpeed` | Макс. входная скорость | Ограничение скорости, переносимой в додж из бега или спринта. |
| `[Motion] fCarryDecay` | Затухание пола скорости | После передачи в бег скорость движка не падает ниже скорости выхода, убывающей с этим темпом (юн/с2). 0 = выкл. |
| `[Motion] bBackstepWithoutInput` | Отскок назад без ввода | Без направления додж идёт назад (иначе вперёд). |

## Страница «Управление и разворот»

| В ini | В меню F7 | Что делает |
|---|---|---|
| `[Steering] fDirectionCommitTime` | Окно выбора направления | Первые секунды, в которые текущий ввод полностью переставляет направление доджа. 0 = только направление при нажатии. Клип может задать своё аннотацией RDF_Commit. |
| `[Steering] fMaxDeviation` | Макс. отклонение рулением | Насколько ввод может увести начатый додж от направления старта. 0 = без руления, 180 = свободно. Клип может задать своё аннотацией RDF_Steer. |
| `[Steering] fInputCone` | Конус ввода | Ввод дальше этого угла от текущего пути игнорируется (при 90 нажатие назад ничего не делает). |
| `[Steering] bInputFromStartCamera` | Ввод от камеры на старте | Ввод считается от камеры на момент старта: поворот камеры не рулит доджем. |
| `[Steering] bHoldFacing` | Держать разворот | Доджи со взглядом в камеру держат стартовый разворот: камера не крутит персонажа во время доджа. |
| `[Steering] fOrientationWarpMax` | Довод тела под клип | Направленные клипы идут шагом 45 градусов; тело доворачивается на остаток угла, не больше этого. 0 = выкл. Клип может задать своё аннотацией RDF_Warp. |
| `[Steering] sOrientation` | Режим взгляда | Авто: в TDM 360 смотреть по пути, иначе сохранять взгляд. Значения: `Auto` = Авто; `FaceMotion` = По пути; `KeepFacing` = Сохранять взгляд. |
| `[Steering] fFaceMotionMaxAngle` | Макс. угол разворота по пути | При свободном повороте доджи шире этого угла сохраняют взгляд (отскок вместо разворота). |
| `[Steering] fRateStartup` | Скорость руления: разгон | Как быстро ввод поворачивает путь в разгоне. Клип может задать своё аннотацией RDF_Steer. |
| `[Steering] fRateActive` | Скорость руления: активная | Как быстро ввод поворачивает путь на пике. Клип может задать своё аннотацией RDF_Steer. |
| `[Steering] fRateRecovery` | Скорость руления: восстановление | Как быстро ввод поворачивает путь в восстановлении. Клип может задать своё аннотацией RDF_Steer. |
| `[Steering] fStartupYawRate` | Поворот тела: разгон | Как быстро поворачивается тело на старте (почти мгновенно). Клип может задать своё аннотацией RDF_YawRate. |
| `[Steering] fFaceYawRate` | Поворот тела | Как быстро тело догоняет нужный разворот дальше. Клип может задать своё аннотацией RDF_YawRate. |
| `[Steering] fDeadzone` | Мёртвая зона стика | Ввод стика ниже этого не рулит. |
| `[Steering] fResponseExponent` | Отклик стика | Кривая силы стика: 1 = линейно, больше 1 = мягче у центра. |

## Страница «Анимация»

| В ini | В меню F7 | Что делает |
|---|---|---|
| `[Graph] fAnimSpeed` | Скорость анимации | Множитель поверх подгонки клипа под длительность доджа. Клип может задать своё аннотацией RDF_Speed. |
| `[Graph] fClipLength` | Длина клипа | Секунды клипа доджа от третьего лица при скорости 1. Клип может задать своё аннотацией RDF_ClipLength. |
| `[Graph] bClipMotion` | Движение клипа | Аннотации клипа RDF_Motion, RDF_ClipLength и RDF_Speed задают дистанцию, фазы, длину клипа и множитель скорости его доджа вместо fDistance, фаз тайминга, fClipLength и fAnimSpeed. |
| `[Graph] fArmStance` | Стойка рук | Доля стойки оружия на руках во время доджа. 1 = защита остаётся. Клип может задать своё аннотацией RDF_ArmStance. |
| `[Graph] bArmStanceWhenSheathed` | Стойка рук без оружия | Держать стойку и с убранным оружием или заклинанием. |
| `[Graph] fArmStanceFirstPerson` | Стойка рук: первое лицо | Доля стойки оружия на руках от первого лица. 1 = хват остаётся на оружии. Клип может задать своё аннотацией RDF_ArmStance. |
| `[Graph] fClipLengthFirstPerson` | Длина клипа: первое лицо | Секунды ванильных 1P-клипов доджа при скорости 1. Клип может задать своё аннотацией RDF_ClipLength. |
| `[Graph] fFirstPersonLookScale` | Поворот мышью от 1-го лица | Поворот мышью во время 1P-доджа: 1 = как обычно, 0 = заблокирован, -1 = наоборот. |

## Страница «Стоимость и правила»

| В ini | В меню F7 | Что делает |
|---|---|---|
| `[Cost] sResource` | Ресурс | Чем оплачивается додж, если у актора нет кейвордов ресурса ниже. Значения: `None` = Бесплатно; `Stamina` = Запас сил; `Magicka` = Магия. |
| `[Cost] fCost` | Стоимость | Основа цены доджа; настройки ниже прибавляются к ней и умножают её. |
| `[Cost] fCostMaxPercent` | Стоимость: процент от максимума | Добавляет к стоимости этот процент от максимума ресурса. |
| `[Cost] fCostWeightMult` | Стоимость за вес снаряжения | Добавляет к стоимости вес надетого снаряжения, умноженный на это число. |
| `[Cost] fChainCostStep` | Удорожание в цепочке | Каждый следующий додж в цепочке дороже: x (1 + шаг x его номер в цепочке). |
| `[Cost] fOverencumberedMult` | Множитель при перегрузе | Стоимость умножается на это при перегрузе (правило игры: только игрок). |
| `[Cost] fCostMin` | Нижний предел стоимости | Стоимость не бывает ниже этого. |
| `[Cost] fCostMax` | Верхний предел стоимости | Стоимость не бывает выше этого; 0 = без предела. |
| `[Cost] sShortfall` | Ресурса не хватает | Refuse: ресурс должен покрыть всю стоимость. Minimum: разрешено от минимума, тратится сколько есть. Always: никогда не отказывать. Значения: `Refuse` = Отказать; `Minimum` = От минимума; `Always` = Всегда доджить. |
| `[Cost] fMinimum` | Минимум для доджа | При «Ресурса не хватает» = От минимума: ниже этого значения ресурса додж не выполняется. |
| `[Cost] fPerfectRefund` | Возврат за идеальный додж | Процент стоимости доджа, который возвращается при идеальном додже. |
| `[Cost] fRegenDelay` | Задержка регенерации | После доджа регенерация оплатившего ресурса ждёт столько (собственная задержка игры, ограничена её максимумом). 0 = нет. |
| `[Cost] fRegenDelayEmpty` | Задержка регенерации при опустошении | Используется вместо обычной, если додж опустошил ресурс. 0 = обычная задержка. |
| `[Cost] bFlashMeter` | Мигание полосы HUD | Полоса игрока мигает, когда додж отклонён из-за нехватки ресурса или опустошил его. |
| `[Cost] sStaminaKeyword` | Платит запасом сил: кейворд | Актор с этим кейвордом (на нём, надетой вещи или активном эффекте) платит за додж запасом сил вместо ресурса стоимости; вместе с кейвордом магии: пополам. |
| `[Cost] sMagickaKeyword` | Платит магией: кейворд | Актор с этим кейвордом платит за додж магией вместо ресурса стоимости; вместе с кейвордом запаса сил: пополам. |
| `[Cost] sCostKeyword` | Кейворд стоимости | Маг-эффекты с ним прибавляют сумму магнитуд к базовой стоимости. Считаются только маг-эффекты с Recover; Detrimental со знаком минус; выключенные условиями и развеянные не считаются. |
| `[Cost] sCostMultKeyword` | Кейворд процента стоимости | Маг-эффекты с ним умножают стоимость на (1 + сумма магнитуд / 100). Считаются только маг-эффекты с Recover; Detrimental со знаком минус; выключенные условиями и развеянные не считаются. |
| `[Cost] sChainCostKeyword` | Кейворд удорожания цепочки | Маг-эффекты с ним прибавляют сумму магнитуд / 100 к удорожанию в цепочке. Считаются только маг-эффекты с Recover; Detrimental со знаком минус; выключенные условиями и развеянные не считаются. |
| `[Perfect] bPerfectDodge` | Идеальный додж | Удар, отменённый i-frames в окне ниже, шлёт RDF_PerfectDodge в граф игрока, RDF_PerfectDodged в граф атакующего и мод-событие RDF_PerfectDodge в Papyrus. Если задан кейворд идеального доджа, только для акторов с ним. |
| `[Perfect] fPerfectWindowStart` | Начало окна идеального доджа | Секунды от начала доджа. Считается только там, где есть i-frames. Клип задаёт своё аннотацией RDF_PerfectStart. |
| `[Perfect] fPerfectWindowEnd` | Конец окна идеального доджа | Секунды от начала доджа. Клип с аннотациями RDF_PerfectStart / RDF_PerfectEnd использует их вместо окна. |
| `[Perfect] sPerfectDodgeKeyword` | Кейворд идеального доджа | Если задан, идеально доджит только актор с этим кейвордом (на нём, надетой вещи или активном эффекте). |
| `[Perfect] sPerfectWindowKeyword` | Кейворд окна идеального доджа | Маг-эффекты с ним меняют окно идеального доджа на сумму магнитуд в миллисекундах, как кейворд i-frames. Считаются только маг-эффекты с Recover; Detrimental со знаком минус; выключенные условиями и развеянные не считаются. |
| `[Perfect] bPerfectGhost` | Фантом на идеальном додже | Идеальный додж оставляет светящийся силуэт доджера на месте срабатывания. Нужен мод Ghost Trails API (GhostTrails.dll). |
| `[Perfect] bPerfectGhostNPC` | Фантом: и у NPC | Идеальный додж NPC тоже оставляет фантом (выключено: только у игрока). |
| `[Perfect] sPerfectGhostColor` | Цвет фантома | Цвет и прозрачность силуэта. |
| `[Perfect] fPerfectGhostIntensity` | Свечение фантома | Насколько ярко светится силуэт. |
| `[Perfect] fPerfectGhostRimPower` | Ободок фантома | Насколько резкий светящийся ободок; 0 = без ободка. |
| `[Perfect] fPerfectGhostLifetime` | Время жизни фантома | Сколько игровых секунд виден силуэт, вместе с исчезновением. |
| `[Perfect] iPerfectGhostCount` | Число фантомов | Силуэтов на идеальный додж; больше одного: короткий шлейф после него. |
| `[Perfect] fPerfectGhostInterval` | Интервал фантомов | Игровые секунды между силуэтами шлейфа. |
| `[Perfect] fPerfectSlowMotion` | Замедление: скорость мира | Скорость мира во время замедления при идеальном додже. 1 = без замедления. |
| `[Perfect] fPerfectSlowMotionPlayer` | Замедление: скорость игрока | Скорость самого игрока в это время. 1 = полная скорость, пока мир замедлен; равна скорости мира = замедлены одинаково. |
| `[Perfect] fPerfectSlowMotionDuration` | Замедление: удержание | Сколько реальных секунд длится полное замедление между входом и выходом. |
| `[Perfect] fPerfectSlowMotionEaseIn` | Замедление: вход | Сколько реальных секунд время замедляется. 0 = сразу. |
| `[Perfect] fPerfectSlowMotionEaseOut` | Замедление: выход | Сколько реальных секунд время возвращается к норме. 0 = сразу. |
| `[Perfect] fPerfectSlowMotionCooldown` | Замедление: перезарядка | Сколько реальных секунд после конца замедления новое не начнётся. Идеальный додж во время замедления продлевает его. |
| `[Rules] sNoDodgeKeyword` | Кейворд запрета доджа | Актор с этим кейвордом (на нём, расе, надетой вещи или активном эффекте) не может доджить. |
| `[Rules] bRespectDisabledControls` | Без доджа при отключённом управлении | Нет доджа, пока игра отключила игроку движение или обзор (сцены, скриптовые блокировки). |

## Только в ini

Эти ключи меню не показывает (хуки, события графа, совместимость): они действуют со старта
игры, их описание в комментариях самого ini.

- `[Input]`: `sIdleReplayChains`
- `[Timing]`: `sAttackStates`
- `[Motion]`: `iYawSign`
- `[Graph]`: `sEventStart`, `sEventStartB`, `sEventChain`, `sEventExit`, `bOneHandDodge`, `sEventStart1H`, `sEventStartB1H`, `sEventStartBow`, `sEventStartBowB`, `sEventExitBow`, `sEventStartMagic`, `sEventStartMagicB`, `sEventExitMagic`, `sVarDodgeLayer`, `sHoldEvents`, `sEventEntered`, `sEventLeft`, `sVarClip`, `sVarSpeed`, `sVarArmBlend`, `sVarIsDodging`, `sVarChainIndex`, `sVarAttackFromDodge`, `sVarAttackFromDodgeClip`, `iEnterTimeoutFrames`, `sDodgeWindowOpenEvents`, `sDodgeWindowCloseEvents`
- `[IFrames]`: `bIFrames`, `bProjectileIFrames`, `bExplosionIFrames`
- `[Perfect]`: `sPlayerEvent`, `sAttackerEvent`, `sModEvent`
- `[AttackCancel]`: `sRecoveryEvents`, `sRecoveryEndEvents`, `sRecoveryVariables`, `sAttackStartEvents`
- `[Compat]`: `bAllowFirstPerson`, `bSuppressLegacyDodge`, `bUseTrueDirectionalMovement`, `bUsePrecision`
- `[Stagger]`: `sRecoveryVariables`, `sRecoveryOpenEvents`, `sRecoveryCloseEvents`, `sStaggerStartEvents`
- `[Casting]`: `sCastingVariables`
